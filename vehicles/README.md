# Notes on specific vehicles

One short file per vehicle that has been built with this skill: what was particular to it. General lessons
belong in [BLENDER.md](../BLENDER.md), not here.

**Using them.** At Step 2, look for a note on your vehicle, or on one built the same way (same maker and
generation, or the same kind of body). Copy it into the project beside `BLENDER.md` and name it in every
builder brief.

**Writing one.** At the handover, write `notes/vehicle-note.md` in the project and tell the user they can add
it here. Keep it under forty lines, in this shape:

```
# <maker, model, generation, years, trim>

Built: <date>, take-apart level <n>, <hours> agent hours.

## References that mattered
Which views solved well, which did not, anything misleading in the maker's pictures.

## Hard parts
The three or four features that took the most rounds, and what finally worked for each.

## Counts and facts worth knowing first
Part counts and proportions that were got wrong before they were got right.

## Left open
Faults still there at sign-off.
```

Say only what is particular to this vehicle and was learned by building it.
